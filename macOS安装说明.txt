课件讲解平台 · macOS 安装说明

【怎么装】
1. 先解压外层 zip（双击即可），得到本说明、macOS安装器.command 和完整包。
2. 双击「macOS安装器.command」。
3. 如果 macOS 提示「无法打开，因为来自身份不明的开发者」，
   请右键该文件 → 选择「打开」→ 再点一次「打开」。只需做这一次。
4. 安装完成后会自动启动，并在桌面生成「启动课件讲解平台.command」。

【如果双击没反应 / 提示没有执行权限】
打开「终端」，把下面这行粘进去回车（注意把路径换成你解压出来的文件夹）：

  chmod +x ~/Downloads/课件讲解平台-macOS-<版本>/macOS安装器.command

然后再双击一次。

【安装位置】
~/Applications/课件讲解平台

【更新时会发生什么】
重新运行安装器会替换掉旧程序，但**你的课件、项目记录和本机配置都会保留**
（data/ 和 .env 不会被删）。

【日常使用】
· 启动：双击安装目录里的「一键安装并启动.command」，或桌面的快捷方式
· 检查更新：双击安装目录里的「检查更新.command」（会下载并安装 GitHub 上的最新版）

【需要什么】
Node.js 20 或更高版本。没有的话「一键安装并启动.command」会引导你安装。
