课件讲解平台 · macOS 使用指南

========================================================
 一、这是什么
========================================================

一个装在你自己电脑上的 AI 学习工具。把课件（PDF / PPTX / DOCX 等）传进去，
它会帮你分析内容、逐页讲解、整理知识点、出练习题、带着做实验。
所有数据都留在这台电脑上，不会上传到别人的服务器。

需要联网，因为它要调用 AI 模型来生成内容。


========================================================
 二、开始之前，先准备两样东西
========================================================

【1】Node.js 20 或更高版本

  检查方法：打开「终端」，输入 node -v 回车。
  显示 v20.x 或更高就没问题。
  没有的话到 https://nodejs.org/zh-cn/download 下载 LTS 版，
  双击 .pkg 一路下一步即可。

  装了 Homebrew 的话也可以：brew install node

【2】一个 DeepSeek API Key（必填）

  这个平台自己不带 AI 能力，要用你自己的 Key 去调用模型。
  没有 Key 的话界面能打开，但任何生成功能都用不了。

  · 到 https://platform.deepseek.com/api_keys 注册并创建
  · Key 形如 sk-xxxxxxxxxxxxxxxx
  · 按用量计费，正常用一份课件几分钱到几毛钱
  · Key 只保存在你自己的浏览器里，随请求发给模型，服务器不存

  也可以用别的兼容服务（硅基流动、Groq 等），在设置里改接口地址和模型名。


========================================================
 三、安装（四步）
========================================================

1. 双击「课件讲解平台-macOS-…zip」解压
   （macOS 会自动解压到「下载」里一个同名文件夹）

2. 进入那个文件夹，找到「macOS安装器.command」

3. 第一次运行会被 macOS 拦下来。
   **不要在「无法打开」的提示框里点「移到废纸篓」**，正确做法是：
   右键点这个文件 → 选「打开」→ 在弹窗里再点一次「打开」。
   只需做这一次，之后就能正常双击了。

4. 看到「安装完成，正在启动…」就成功了。
   会自动打开一个终端窗口并启动浏览器 http://127.0.0.1:4173

安装位置：~/Applications/课件讲解平台
桌面会生成一个「启动课件讲解平台.command」，以后双击它就能用。


========================================================
 四、第一次打开：填 API Key
========================================================

界面右上角如果显示「未配置 API Key · 点此填写」：

1. 点它（或点右上角「设置」）
2. 把 sk-... 开头的 Key 粘进去
3. 点「保存并测试」，看到「已保存并验证通过」就好了

Key 存在浏览器里，换浏览器或清了浏览器数据要重新填一次。


========================================================
 五、日常使用
========================================================

【启动】
  双击桌面的「启动课件讲解平台.command」。
  会打开一个终端窗口，**这个窗口要一直开着** —— 它就是程序本体，
  关掉窗口等于关掉程序。然后浏览器访问 http://127.0.0.1:4173

【停止】
  在终端窗口里按 Control+C，或者直接关掉那个窗口。

【数据存在哪】
  安装目录下的 data 文件夹。
  · data/uploads  你上传的原始文件
  · data/cache    项目数据（分析结果、做题记录、对话……）

【备份】
  整个 data 文件夹复制走就行。换电脑时把新装的 data 覆盖进去，
  项目和记录都会回来。

【注意】
  · 只有开着程序时网址才能打开，这是正常的（本机服务）
  · 首次启动 macOS 可能询问是否允许接受传入连接，选「允许」；
    只监听本机，外网访问不到
  · 默认 14 天没动过的项目会被自动清理，重要内容记得导出或备份


========================================================
 六、更新到新版本
========================================================

方式一（推荐）：重新跑一遍新版本的安装器
  下载新版压缩包 → 解压 → 右键「打开」运行 macOS安装器.command
  旧程序会被替换，**data 文件夹和 .env 配置都会保留**。

方式二：用程序自带的检查更新
  双击安装目录里的「检查更新.command」，
  它会去 GitHub 拉最新完整包、校验后自动替换并重启。


========================================================
 七、常见问题
========================================================

Q：双击安装器提示「无法打开，因为来自身份不明的开发者」
A：右键点文件 → 「打开」→ 再点「打开」。只需确认这一次。

Q：双击后提示「你没有权限打开」或者根本没反应
A：给文件加上执行权限。打开「终端」，把下面这行粘进去回车
   （路径换成你实际解压出来的文件夹）：

     chmod +x ~/Downloads/课件讲解平台-macOS-*/macOS安装器.command

   然后再双击一次。

Q：提示 command not found: node
A：没装 Node.js，或者装了但当前终端不认识。
   先装 Node（见第二节），装完**关掉所有终端窗口**再重试。

Q：网址打不开 / 提示无法访问
A：1) 确认那个终端窗口还开着；2) 换个浏览器试试；
   3) 如果提示端口被占用，说明已经有一个实例在跑，先关掉旧的窗口。

Q：生成时提示 API Key 相关错误
A：右上角「设置」里重新填一次 Key，点「保存并测试」。
   如果提示余额不足，去 DeepSeek 控制台充值。

Q：上传的课件读不出内容
A：扫描版 PDF（整页是图片、没有文字层）需要先做 OCR。
   平台会提示你。可以先用「预览」另存为可选中文字的 PDF 再上传。

Q：想把程序装到别的位置
A：安装器默认装到 ~/Applications/课件讲解平台。想换位置的话，
   直接把解压出来的 courseware-platform 文件夹放到任意位置，
   然后在里面双击「一键安装并启动.command」即可（那种方式不写安装目录）。

Q：想让同一个局域网的同学也能用
A：在安装目录里打开终端，运行：
     HOST=0.0.0.0 npm start
   然后别人用你的内网 IP 访问。注意这会关掉服务端 Key，
   访客需要自己填 Key。


========================================================
 八、卸载
========================================================

1. 删掉安装目录：~/Applications/课件讲解平台
   （**想保留项目就先备份里面的 data 文件夹**）
2. 删掉桌面的「启动课件讲解平台.command」
3. 在「系统设置 → 通用 → 登录项与扩展」里检查有没有残留项
4. Node.js 如果不打算他用，可以用 brew uninstall node 卸载
