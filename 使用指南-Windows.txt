课件讲解平台 · Windows 使用指南

========================================================
 一、这是什么
========================================================

一个装在你自己电脑上的 AI 学习工具。把课件（PDF / PPTX / DOCX 等）传进去，
它会帮你分析内容、逐页讲解、整理知识点、出练习题、带着做实验。
所有数据都留在这台电脑上，不会上传到别人的服务器。

需要联网，因为它要调用 AI 模型来生成内容。


========================================================
 二、开始之前，先准备两样东西
========================================================

【1】Node.js 20 或更高版本

  安装器会自动检测。没有的话它会让 winget 帮你装；
  如果 winget 不可用，会打开官网让你手动装：
  https://nodejs.org/zh-cn/download  （选 LTS 版，一路下一步即可）

【2】一个 DeepSeek API Key（必填）

  这个平台自己不带 AI 能力，要用你自己的 Key 去调用模型。
  没有 Key 的话界面能打开，但任何生成功能都用不了。

  · 到 https://platform.deepseek.com/api_keys 注册并创建
  · Key 形如 sk-xxxxxxxxxxxxxxxx
  · 按用量计费，正常用一份课件几分钱到几毛钱
  · Key 只保存在你自己的浏览器里，随请求发给模型，服务器不存

  也可以用别的兼容服务（硅基流动、Groq 等），在设置里改接口地址和模型名。


========================================================
 三、安装（四步）
========================================================

1. 把「课件讲解平台-Windows-…zip」完整解压出来
   右键 → 全部解压缩。**不要在压缩包里直接双击运行**，
   也不要把安装器单独拖出来 —— 它需要和完整包放在一起。

2. 进入解压出来的文件夹，双击「Windows安装器.cmd」

3. 如果弹出蓝色的「Windows 已保护你的电脑」：
   点「更多信息」→ 再点「仍要运行」。
   这是 SmartScreen 对不明来源脚本的例行提示，只需确认这一次。

4. 看到「安装完成，正在启动…」就成功了。
   浏览器会自动打开 http://127.0.0.1:4173

安装位置：%LOCALAPPDATA%\Programs\课件讲解平台
桌面会生成一个「启动课件讲解平台.cmd」，以后双击它就能用。


========================================================
 四、第一次打开：填 API Key
========================================================

界面右上角如果显示「未配置 API Key · 点此填写」：

1. 点它（或点右上角「设置」）
2. 把 sk-... 开头的 Key 粘进去
3. 点「保存并测试」，看到「已保存并验证通过」就好了

Key 存在浏览器里，换浏览器或清了浏览器数据要重新填一次。


========================================================
 五、日常使用
========================================================

【启动】
  双击桌面的「启动课件讲解平台.cmd」。
  会弹出一个黑色窗口，**这个窗口要一直开着** —— 它就是程序本体，
  关掉窗口等于关掉程序。然后浏览器访问 http://127.0.0.1:4173

【停止】
  在黑色窗口里按 Ctrl+C，或者直接关掉那个窗口。

【数据存在哪】
  安装目录下的 data 文件夹。
  · data\uploads  你上传的原始文件
  · data\cache    项目数据（分析结果、做题记录、对话……）

【备份】
  整个 data 文件夹复制走就行。换电脑时把新装的 data 覆盖进去，
  项目和记录都会回来。

【注意】
  · 只有开着程序时网址才能打开，这是正常的（本机服务）
  · 防火墙如果询问是否允许联网，选「允许」；只监听本机，外网访问不到
  · 默认 14 天没动过的项目会被自动清理，重要内容记得导出或备份


========================================================
 六、更新到新版本
========================================================

方式一（推荐）：重新跑一遍新版本的安装器
  下载新版压缩包 → 解压 → 双击「Windows安装器.cmd」
  旧程序会被替换，**data 文件夹和 .env 配置都会保留**。

方式二：用程序自带的检查更新
  双击安装目录里的「检查更新-Windows.cmd」。
  它会去 GitHub 拉最新完整包、校验 SHA-256 后自动替换并重启，
  同样会保留 data 和 .env。


========================================================
 七、常见问题
========================================================

Q：双击安装器，黑窗口闪一下就没了
A：多半是没解压就直接运行。请先「全部解压缩」，再到文件夹里双击。

Q：提示「无法识别为内部或外部命令」或中文全是乱码
A：文件在解压/传输过程中编码被改了。
   先重新完整解压一次；仍然不行，就把文件放到纯英文路径下再试
   （例如 D:\cw\），路径里不要有中文和空格。

Q：提示找不到 Node.js
A：去 https://nodejs.org/zh-cn/download 装 LTS 版，装完**关掉所有窗口**
   再重新双击安装器（新装的 Node 需要新开窗口才能被识别）。

Q：网址打不开 / 提示无法访问
A：1) 确认那个黑色窗口还开着；2) 换个浏览器试试；
   3) 如果提示端口被占用，说明已经有一个实例在跑，先关掉旧的窗口。

Q：生成时提示 API Key 相关错误
A：右上角「设置」里重新填一次 Key，点「保存并测试」。
   如果提示余额不足，去 DeepSeek 控制台充值。

Q：上传的课件读不出内容
A：扫描版 PDF（整页是图片、没有文字层）需要先做 OCR。
   平台会提示你。可以先用别的工具转成可选中文字的 PDF 再上传。

Q：双击「检查更新-Windows.cmd」提示缺少依赖
A：它会自动补装 jszip。如果失败，在安装目录里打开命令行手动跑一次
   npm install --no-audit --no-fund，然后再双击。

Q：想让同一个局域网的同学也能用
A：在安装目录里打开命令行，运行：
     set HOST=0.0.0.0 && npm start
   然后别人用你的内网 IP 访问。注意这会关掉服务端 Key，
   访客需要自己填 Key。


========================================================
 八、卸载
========================================================

1. 删掉安装目录：%LOCALAPPDATA%\Programs\课件讲解平台
   （**想保留项目就先备份里面的 data 文件夹**）
2. 删掉桌面的「启动课件讲解平台.cmd」
3. Node.js 如果不打算他用，可以在「设置 → 应用」里卸载
