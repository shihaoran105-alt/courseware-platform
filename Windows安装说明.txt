课件讲解平台 · Windows 安装说明

【怎么装】
1. 先完整解压「课件讲解平台-Windows-…zip」（右键 → 全部解压缩）。
   **不要**在压缩包里直接双击运行，也不要把安装器单独拖出来。
2. 双击「Windows安装器.cmd」。
3. 如果 Windows 弹出安全提示（SmartScreen），点「更多信息」→「仍要运行」。
4. 安装完成后会自动启动，并在桌面生成「启动课件讲解平台.cmd」。

【安装位置】
%LOCALAPPDATA%\Programs\课件讲解平台

【更新时会发生什么】
重新运行安装器会替换掉旧程序，但**你的课件、项目记录和本机配置都会保留**
（data 文件夹和 .env 不会被删）。

【日常使用】
· 启动：双击桌面的「启动课件讲解平台.cmd」
· 检查更新：在安装目录里运行更新脚本（会下载并安装 GitHub 上的最新版）

【需要什么】
Node.js 20 或更高版本。没有的话「一键安装并启动-Windows.cmd」会用 winget 自动装，
装不了会打开官网让你手动装。

【如果提示「无法识别为内部或外部命令」或中文显示成乱码】
说明文件在解压或传输过程中编码被改了。请重新完整解压一次；
仍然不行的话，把安装目录和文件名里的中文换成英文再试（例如 C:\cw\）。
